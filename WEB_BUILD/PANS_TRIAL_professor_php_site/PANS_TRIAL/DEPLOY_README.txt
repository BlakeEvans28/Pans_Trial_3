Pan's Trial PHP Website Package

Upload or extract the PANS_TRIAL folder under the website's PROJECTS directory.
Expected game URL:
https://drpeterjamieson.com/PROJECTS/PANS_TRIAL/index.html

index.html is configured to use room_server.php in this same directory.
room_server.php stores room JSON files in pan_trial_room_data, which is included here.
The web host must allow PHP to write files in pan_trial_room_data.
